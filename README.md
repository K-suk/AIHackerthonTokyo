# 声レジ

カフェ店員の復唱を、写真付きの注文チケットに変える Next.js アプリ。

## ローカル起動

```sh
npm ci
npm run dev -- --hostname 127.0.0.1
```

ターミナルに表示されたURLを開くと、「サンプル注文」「警告例」、タップでの商品追加が使えます。

実際の音声を使う場合は、`.env.example` をもとに `.env.local` を作り、`AQUA_API_KEY` と `OPENAI_API_KEY` を設定してサーバーを再起動します。対面でも電話でも「録音開始」を押して注文を復唱すると、短い無音を検出して自動で文字起こし・注文解析を行います。後で受け取る注文では、名前と受取時刻がそろった伝票を受取リストに追加します。

モックメニューは `fukusho-menu-mock.json`、開発フェーズと完了条件は [実装計画](koe-register-implementation-plan.md) にあります。
