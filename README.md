# 声レジ

カフェでの注文の会話を、写真付きの注文チケットに変える Next.js アプリ。

## ローカル起動

```sh
npm ci
npm run dev -- --hostname 127.0.0.1
```

ターミナルに表示されたURLを開くと、「サンプル注文」「警告例」、タップでの商品追加が使えます。

実際の音声を使う場合は、`.env.example` をもとに `.env.local` を作り、`AQUA_API_KEY` と `OPENAI_API_KEY` を設定してサーバーを再起動します。対面でも電話でも「録音開始」を押して注文のやり取りを録音します。店員の復唱とお客さんが直接伝えた注文のどちらも解析できます。「録音を終了」を押すか、約4秒間無音になると注文を解析します。

伝票が出た後は「追加を録音」で現在の伝票に品目を足せます。次のお客さんには「新しい注文」を使います。後で受け取る注文では、名前と受取時刻がそろった伝票を受取リストに追加します。

モックメニューは `fukusho-menu-mock.json`、開発フェーズと完了条件は [実装計画](koe-register-implementation-plan.md) にあります。
